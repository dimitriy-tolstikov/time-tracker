# Time Tracker

[English version](README.md)

Настольное WPF-приложение для Windows, которое автоматически отслеживает время во всех активных окнах: пишет интервалы активности (процесс, заголовок окна, URL для Edge), классифицирует их на проекты по настраиваемым правилам и строит статистику по проектам с уведомлениями.

## Возможности

- **Автоматический лог активности** — активное окно опрашивается каждые 2 секунды; интервалы пишутся в SQLite с именем процесса, заголовком окна и флагом простоя (нет ввода с клавиатуры/мыши). Мусор от Alt-Tab отфильтровывается.
- **Проекты и правила классификации** — интервалы назначаются на проекты по правилам: точное имя процесса, фрагмент заголовка окна или URL (подстрока или regex, с приоритетами). Неклассифицированные интервалы разбираются вручную из списка «Неразобранное», опционально с созданием правила.
- **URL вкладки Edge** — URL активной вкладки Edge извлекается через UI Automation и сохраняется с интервалом (Firefox/Chrome пока вне скоупа).
- **Статистика по проектам** — список проектов с суммой времени за выбранный день и график дня в двух режимах: «По проектам» (почасовой стек) и «Хронология» (лента интервалов 00:00–24:00).
- **Уведомления по проектам** — предупреждение, если в проекте нет активности N минут, или превышен дневной лимит проекта (окно поверх всех окон с отложкой). У каждого уведомления настраивается уровень серьёзности (белый/жёлтый/красный) — цвет и звук окна; срабатывание — с точностью до долей секунды (таймер адаптивный, без частого опроса).
- **История по дням** — список дней с суммарным отработанным временем, автоматический переход через полночь (интервалы разрезаются на границе дня).

## Стек

- C# / .NET 8 (`net8.0-windows`)
- WPF + Windows Forms (глобальные хуки ввода через Win32 API)
- MVVM (Models / ViewModels / Services / Converters)
- SQLite (`Microsoft.Data.Sqlite`) + Dapper для хранения
- FlaUI (UIA3) для чтения адресной строки Edge

## Структура проекта

```
.
├── Models/                        # ActivityInterval, Project, ClassificationRule и UI-модели
├── ViewModels/                    # MainViewModel, ProjectsViewModel, RelayCommand
├── Services/                      # WindowWatcherService, Database, IntervalRepository,
│                                  # ProjectRepository, ClassificationService, StatsService,
│                                  # NotificationService, EdgeUrlProvider, InputHooks и др.
├── Converters/                    # XAML-конвертеры
├── tools/                         # IconConverter — утилита для иконки (исключена из сборки)
├── MainWindow.xaml                # главное окно
├── ProjectsWindow.xaml            # окно управления проектами и правилами
├── InactivityWarningWindow.xaml   # окно уведомления
└── TimeTracker.sln
```

## Требования

- Windows
- .NET 8 SDK (точная версия закреплена в `global.json`)

## Сборка и запуск

Через .NET CLI:

```bash
dotnet build
dotnet run --project TimeTracker.csproj
```

Или откройте `TimeTracker.sln` в Visual Studio и запустите проект (F5).

## Где хранятся данные

Все данные — в единой БД SQLite `%LocalAppData%\TimeTracker\tracker.db`: интервалы активности, проекты, правила классификации и настройки приложения (таблица `settings`). Старые `config.json` / `history.json` новая версия не читает и не пишет — ими продолжает владеть параллельно работающая старая версия.
