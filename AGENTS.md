# AGENTS.md

## Сборка

- `dotnet build` — WPF-приложение, net8.0-windows, без тестового проекта.
- **Запущенный пользователем процесс TimeTracker убивать нельзя** (в т.ч. ради
  пересборки: он держит `bin/Debug/.../TimeTracker.exe`). Приложение пишет
  интервалы в БД на лету и при штатном закрытии; принудительное завершение
  теряет текущий открытый интервал. Пересборку согласовываем с пользователем,
  а для проверки компиляции, пока приложение запущено, собираем в отдельный
  каталог: `dotnet build -p:OutDir=obj/buildcheck/`.

## UI-конвенции

- **Новые окна (`Window`) не создаём без явного подтверждения пользователя.**
  Новый функционал добавляем вкладками (`TabItem`) в `MainWindow`, а содержимое
  вкладки — отдельным `UserControl` в своей паре файлов (`SomethingView.xaml` +
  `.xaml.cs`), чтобы главное окно не раздувалось.
- В `DataTemplate` у привязок `Run.Text` всегда указывать `Mode=OneWay`:
  у `Run.Text` режим по умолчанию TwoWay, и на read-only свойстве рендер падает
  с `XamlParseException`.
- `Popup` живёт в отдельном визуальном дереве: `DataContext` в него не наследуется,
  пробрасываем вручную в code-behind (см. `ProjectsView.ColorButton_Click`).

## База данных

- SQLite (`%LocalAppData%/TimeTracker/tracker.db`), схема версионируется через
  `PRAGMA user_version` в `Services/Database.cs`. Изменения схемы — только новой
  миграцией с повышением версии; свежая БД создаётся сразу в актуальной схеме.
- Пороги времени (неактивность, лимиты) храним в секундах.
